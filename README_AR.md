# تعديلات تطبيق فهمت — الدفعة الثانية (تشمل الأولى)
انسخ الملفات فوق نفس المسارات ثم: flutter pub get && flutter build apk

## جديد في هذه الدفعة: القائمة الجانبية وصفحات المفهمين والمستفهمين
- زر "المزيد" في شريط التنقل السفلي (أو سحب من الحافة) يفتح lib/hub/app_drawer.dart
- الاستفهامات: تصفح الاستفهامات، طرح استفهام، استفهاماتي، تفاصيل الاستفهام، تقديم/تعديل عرض
- المفهمون: تصفح المفهمين، ملف المفهم، تصفح أعمال المفهمين، تفاصيل العمل، عروضي
- تبديل الوضع مفهم/مستفهم (users/{uid}.role) كما في المنصة
- الصفحات التعريفية (الدليل، الشروط، الخصوصية...) والمحفظة تُفتح داخل التطبيق كمتصفح مدمج
- قبول العرض يفتح صفحة الدفع على المنصة (التطبيق بدون دفع)
كلها تقرأ وتكتب في نفس مجموعات Firebase (istifhams / offers / portfolio / users / categories) بدون أي تكرار.

## من الدفعة الأولى
مشغل الفيديو بأزرار فوق الفيديو، غرفة الميتنج (مايك وكاميرا مقفولين + مشاركة شاشة + سبورة + ملفات)، تغيير الاسم لـ "فهمت"، إضافة file_picker.
